# Schedules, Process Map, Responsibility Matrix

Working set for the 2026-11 workstream on schedule tracking, the process map, and the role / responsibility matrix. Everything here is non-sensitive operating material. Compensation, reviews, and person-level personnel data are kept out of this repository on purpose (see `01-storage-recommendation.md`).

| File | What it is |
|---|---|
| `01-storage-recommendation.md` | Where this material should live (this repo vs. BBL-DataSource vs. SharePoint), with the constraint that this repository is public. |
| `02-process-map-history.md` | Timeline and goals of the process map effort, May 2024 to date, reconstructed from Outlook and SharePoint. |
| `03-critical-date-calendar.md` | The Critical Date Calendar artifact: what it does, where the dates came from (historical sheet, the weekly Planner task grids, PM Reports and the DD Exit baselines in BBL-DataSource), how Planner was reached, the data model, how it trees down to sub-schedules, and the open completeness questions. |
| `04-job-description-inventory.md` | Every job description found on SharePoint, where it lives, when it was last touched, roles with no JD, and the review template for department heads. |
| `05-personnel-and-bamboo.md` | Org chart status, the BambooHR API investigation, and the Bamboo title / department discrepancies to fix. |
| `06-project-email-mailboxes.md` | The community project email mailboxes: what was set up, the weekly Claude summaries Kurt already runs, the gaps, and a phased plan to turn them into warehouse tables, calendar signals and reporting. |
| `critical-date-calendar.html` | Source of the published artifact. The process-map template (53 milestones, 9 stages) is embedded; community dates live in the artifact's shared database, not in this file. |
